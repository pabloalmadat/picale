Si todo sale en rojo

404 — la ruta no es esa. Entra por SSH y busca dónde escribe los segmentos: 
find / -name "*.m3u8" -mmin -60 2>/dev/null
docker ps          # revisa el contenedor de nginx-rtmp
docker exec -it <contenedor> ls /opt/data/hls
Bloqueo de CORS — el archivo existe pero otro dominio no puede leerlo. En el bloque del HLS en nginx: 
location /hls {
    add_header Access-Control-Allow-Origin * always;
    add_header Cache-Control no-cache always;
    types { application/vnd.apple.mpegurl m3u8; video/mp2t ts; }
    root /opt/data;
}
Mixed content — si la página va por HTTPS y el HLS por HTTP, el navegador lo corta sin avisar. Los dos tienen que ser HTTPS.
